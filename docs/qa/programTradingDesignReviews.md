## 검증

- UI 변경 파일 ESLint: 통과.
- `npm run typecheck`: 통과.
- root의 실제 브라우저 확인에서 다이어그램 iframe 표시, 엔진 미실행 503 안내, 계좌 READ 연결 확인. 718폭 시작버튼 줄바꿈 지적을 `whitespace-nowrap` + `sm:flex-none`로 수정.
- 디자인 기존 토큰만 재사용, 원시 hex/px 추가 없음.
- `npx --no-install @google/design.md lint docs/design/local-program-trading.md`는 패키지가 로컬에 없어 npm 레지스트리 조회 중 ENOTFOUND로 실행 불가. 디자인 lint 통과로 보고하지 않는다.
- 실제 주문·체결 UI 검증은 수행하지 않았다. 현재 운용 엔진이 합성 시세/가상 체결이며, 이 한계를 화면에서 명시한다.
