## 비판적 검토와 한계

4개 투자자 분석 역할이 직접 반론을 교환했다. 완료봉·추격 상한·비용 반영·짧은 보유·연패 중지에 합의했으며, 계좌 목표를 위해 위험이나 거래를 강제 확대하는 방식과 다수 신규 필터 동시 도입은 배제했다. 독립 리뷰가 찾아낸 정수반올림 비용 누락과 과거 규칙 감사 혼용을 수정하고 회귀 테스트로 고정했다.

오늘 손절 7건 중 5건은 4분 이내, 유일한 익절은 약 6.29분이었다. 최대 5분 정책이 오늘 성과를 개선했거나 새 전략이 양의 기대수익을 가진다는 근거는 없다. 오늘 원장에는 당시 원시 입력이 없어 변경전후 성과 재생이 불가능하다.

브라우저 두 뷰포트 육안 검사는 수행하지 않았다. UI 구조·스타일·토큰을 바꾸지 않고 사유·한도 카피를 갱신했다. 다이어그램은 생성기의 구조·품질 검사와 BFF 제공 테스트로 확인했다. 실제 시세를 이용한 신규 v5 세션, 원격 배포·push·실제 주문은 실행하지 않았다. 사용자가 서버를 재시작하고 새 세션으로 모의 검증한다.

서버가 잠들거나 중지된 동안에는 5분/30초 보호도 실행되지 않는다. 복구 시 안전 종료하며, 마지막 기록가 정산은 실제 체결 보장이 아니다. 세션 제한은 새 세션에서 초기화되고 날짜별 누적 제한은 구현하지 않았다. 최우선 bid 전량 청산 가정은 호가 깊이·대기열·시장충격을 재현하지 않는다.
