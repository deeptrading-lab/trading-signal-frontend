## 검증 명령
`npm run test -- lib/server/programTrading/__tests__`: 5파일 27테스트 통과.
`npm run program:rules:check`: 요약·상세 생성일치 통과.
`npm run typecheck`: 통과. 브라우저 검증 최종 결과는 통합 담당 보고를 따른다.

## 필수 잔여 범위
요구2의 **계정만 입력하고 실제 자동매매 즉시 실행**은 미완료다. 현재 연결은 실제 잔액 조회이고 매매는 합성 시세/가상계좌 리플레이다. 실시간 시세·주문·부분체결·취소·잔고대사·실제 장 시간·상시 워커 검증이 추가로 필요하다. 실계좌 거래후 잔액·수익률도 아직 제공하지 않는다. 이 한계를 공개한 부분 구현으로 판정하며 전 요구 완료나 실계좌 출시 승인으로 해석하지 않는다.
