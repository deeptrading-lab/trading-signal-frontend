## 6. 잔여 리스크

1. **상한 상향은 증상 처치다.** PM 중앙값이 10일 만에 155s → 261s (+68%) 로 올랐고, 원인은 PM 프롬프트에 규칙이 계속 누적된 것이다. 900초도 언젠가 잠식된다 — 신설 테스트가 다시 알려주겠지만, 근본 해법은 **PM 이 판단할 것을 코드로 내리는 것**.
2. **진짜 hang 일 때 대기가 길어진다.** 480s → 900s 이므로 CLI 가 응답 없이 매달리면 최대 7분 더 기다린다. 다만 관측된 실패는 hang 이 아니라 정상 동작의 초과였고, 12분 분석 전체를 잃는 비용이 훨씬 크다.
3. **A/B 하니스가 `debateRounds` 를 3 이상으로 올리면** 최악 경로가 늘어 슬랙을 잠식한다. 계산식이 `DEBATE_ROUNDS` 를 참조하도록 고쳐 상수 변경은 따라가지만, **요청별 override 는 테스트가 잡지 못한다**(진단용 경로라 수용).
