# QA — 리서치매니저 객관 근거 주입 + 편향 방지 (rm-judge-grounding)

- 대상 PR: `feature/rm-judge-grounding`
- 범위: 토론 판정 단계(리서치매니저)의 ① recency/순서 편향(약세가 항상 마지막) 완화 ② 판정 근거 객관화(중립 시그널+원시 리포트). 트레이더에도 편향 방지 1줄.
- 배경: 토론은 `강세R1→약세R1→강세R2→약세R2`라 **약세가 마지막 발언** + RM/트레이더/PM 프롬프트가 모두 **강세→약세 순**이라 약세가 컨텍스트 마지막. RM은 `priceContext`+양측 논거만 받아 **원자료(ground truth)·중립 시그널 없이 "수사"를 판정**. A/B 4종목 전부 UNDERWEIGHT(약세)로 나온 정황과 결이 맞음.

## 변경 (lib/prompts/stock/aiAnalysis.ts)
- **RM system**: 편향 방지 원칙 추가 — 강세·약세 동등 가중, **발화 순서·마지막 발언에 휩쓸리지 말 것**, 각 주장을 [객관 검증 근거]와 대조해 데이터 타당성으로 판정, 과장·누락·왜곡 시 가중치↓.
- **RM user**: 강세·약세 논거 **다음(맨 뒤)**에 [객관 검증 근거] 블록 추가 — `signalSummary`(결정론 중립 점수) + 기술/뉴스/펀더멘털/심리 **원시 리포트 4종**. → RM이 마지막으로 읽는 게 약세 주장이 아니라 **중립 원자료**(구조적 recency 완화) + ground truth 확보.
- **트레이더 system**: 편향 방지 1줄(순서·마지막 발언 아닌 데이터 근거로 판단).
