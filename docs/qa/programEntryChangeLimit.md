`rules.template.html`에 0% 초과·20% 이하와 제외 분기를 반영했다. `npm run program:rules`로 `rules.html`은 재생성됐다. 다만 후속 Archify 렌더링 단계가 기본 경로 `/Users/a454155/.codex/skills/archify/bin/archify.mjs`의 파일 부재로 실패했다. `npm run program:rules:check`도 같은 이유로 실패했다. 별도 요약·상세 다이어그램과 브라우저 검증은 미완료이며 Archify 설치 후 재생성·검증해야 한다.

후속 작업에서 기존 도구 위치 `.local/program-trading/tooling/archify`를 확인했다. 이 경로를 `ARCHIFY_HOME`으로 지정해 전체 다이어그램 생성·일치 검증과 실제 Chrome의 매수 다이어그램 자동 검사를 완료했다. 상승률 상한도 생성 다이어그램에 반영됐다. 상세 결과는 [잔여 현금 신규 매수 QA](programCashReinvestment.md)를 따른다.
