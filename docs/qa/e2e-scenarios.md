# FinSight E2E 테스트 시나리오 카탈로그

> **목적**: 브라우저 E2E 자동화(Playwright 등)의 기반 문서. 메뉴별·depth별 **모든** 사용자 시나리오를 `사전조건 → 액션 → 기대결과`로 열거한다. **누락 없음**이 최우선.
>
> **작성 근거**: 2026-07-04 로컬 dev(`MARKET_DATA_SOURCE=toss`, port 3100) + prod에서 화면·기능을 직접 클릭하며 검증. 각 시나리오의 검증 위치를 표기한다.

## 표기 규약
- **[P]** 페이지 로드/렌더 · **[A]** 액션(클릭·입력·hover·롱프레스) · **[N]** 페이지 전환 · **[2D]** 2-depth(모달·시트·인라인 확장) · **[3D]** 3-depth(중첩 라우트/오버레이)
- **색 규약(한국식)**: 상승/이익/적중 = **빨강**, 하락/손실/미적중 = **파랑**
- **검증**: `✅prod`(prod 실물) · `✅local`(localhost TOSS) · `⚠️`(데이터 제약으로 상태만) · `🔍`(자동화 시 필수 확인)

## 데이터 소스 주의 (E2E 환경 설계 시 필수)
| 도메인 | 소스 | 로컬(TOSS) | prod |
|---|---|---|---|
| 종목 시세·일봉/분봉 차트·기업개황·공시 | TOSS/OpenDART | ✅ 실동작 | ✅ |
| 지수 스트립·실시간 랭킹·수급 Top10·관심종목 시세 | **KIS** | ❌(점검 시 폴백/에러) | ✅(키 등록 시) |
| 공포탐욕 | CNN+코스피 합성 | ✅ | ✅ |
| 자가채점·페이퍼 세션 | Supabase | ✅(테이블 有) | ✅ |
| AI 종합분석·단타 판단 | 로컬 CLI(Codex/Claude) | 로컬만 | 큐→로컬워커 |
- ★ E2E 자동화는 **KIS 의존 화면을 위해 stub/mock 서버** 또는 prod 키 필요. 로컬 TOSS만으로는 지수·랭킹·수급·관심종목 populated 상태를 못 만든다(에러/빈 상태는 재현 가능).
