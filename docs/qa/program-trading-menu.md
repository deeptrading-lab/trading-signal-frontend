- 후속 스펙은 `docs/prd/stock-order-integration.md`, 3라운드 검토는 `programTradingLiveReviews.md`와 `programTradingLiveTraderReviews.md` 및 디자이너 기록 후속 절을 따른다.
- 엔진/원장/후보/계좌/BFF/브로커/REST/실시세: 11파일 71테스트 통과. 실제 주문 없이 fake broker와 응답 fixture로 접수/부분체결/취소경합/결과불명/저장실패/재시작/실제비용 정산/휴장·기존보유 사전 차단 검증.

- 브라우저: 실전 모드 표시·마스킹 계좌·매수1회 한도·지정가/시장가 구분·휴장 안내 및 시작 비활성화 확인. 데스크톱과390폭 모바일 확인. 실제 매매 시작 버튼은 누르지 않음.
- 프로덕션 빌드(`npm run build`)·요약/상세 HTML 재생성·일치 검사·타입검사·수정 모듈 ESLint·diff whitespace 검사 통과.
