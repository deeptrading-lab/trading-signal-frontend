## 새 컴퓨터 시작 재검증

별도 작업 복사본에서 Node 22.20.0으로 `npm ci`와 webpack 빌드를 실행했다. 로그인·DB 설정 없이 토스와 한투 조회 설정만 전달한 개발 서버에서 페이지와 후보 API가 각각 HTTP 200을 반환했고 실제 후보 17개를 확인했다. 점검 CLI 직후 첫 서버 조회가 한 차례 비었고, 이후 새로 켰을 때 첫 조회에 성공했다. 시작 가이드는 서버를 먼저 실행하고 별도 CLI는 문제 진단 시에만 쓰도록 정리했다.
