## AI 단타 추천 후보 연동

로컬 서버에서 AI 단타 수급·거래량 응답이 모두 실제 데이터(`X-Data-Source: kis`)인 것을 확인했다. 두 추천 목록을 합친 17개 종목의 코드와 순서가 모의매매 후보와 일치했다. 관련 테스트 25개와 타입·린트·다이어그램 일치 검사를 통과했다.

## 새 컴퓨터 시작 재검증

별도 작업 복사본에서 Node 22.20.0으로 `npm ci`와 webpack 빌드를 실행했다. 로그인·DB 설정 없이 토스와 한투 조회 설정만 전달한 개발 서버에서 페이지와 후보 API가 각각 HTTP 200을 반환했고 실제 후보 17개를 확인했다. 점검 CLI 직후 첫 서버 조회가 한 차례 비었고, 이후 새로 켰을 때 첫 조회에 성공했다. 시작 가이드는 서버를 먼저 실행하고 별도 CLI는 문제 진단 시에만 쓰도록 정리했다.

11월 9일 토스 캘린더의 정규장 09:00~15:30을 조회했다. 장중 응답 fixture에서는 빈 원장으로 접속 후 시작 명령이 HTTP 200, `running: true`로 전환됐다. 타입·린트와 관련 테스트 94개가 통과했다. 실제 장중 가상 체결은 거래일에 확인한다.
