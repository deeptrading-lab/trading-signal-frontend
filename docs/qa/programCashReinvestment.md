## 코드 검증

- 프로그램 매매 엔진·런타임·원장·BFF·다이어그램 구조 테스트: 15개 파일, 121개 통과.
- `npm run typecheck`: 통과.
- 변경한 TypeScript 파일 ESLint: 최종 재검사 통과.
- `git diff --check`: 통과.
- 시세와 파일 저장은 mock으로 대체했다. 실행 중인 세션, 실제 시세, 실계좌 주문은 변경하지 않았다.

## 기준·플로우 검증

- PRD·운용 가이드·화면 안내·`rules.template.html`을 같은 기준으로 변경했다.
- `ARCHIFY_HOME="$PWD/.local/program-trading/tooling/archify" npm run program:rules`: 요약·상세·매수·매도·정산 HTML 및 workflow JSON 생성 완료.
- 같은 `ARCHIFY_HOME`에서 `npm run program:rules:check`: 일치 확인 통과.
- 실제 Chrome 전체 흐름·매수·매도 다이어그램 자동 검사: 경계·가독성·뷰어·테마 검사 통과. 스크린샷을 통한 시각 검수는 실행하지 않았다.

## 적용

개발 서버 재시작 후 이전 규칙의 세션을 종료·보관하고 새 세션에서 사용한다. v7 세션에 새 매수 기준을 섞지 않으며, 이전 보유분 종료와 과거 복기에는 해당 버전의 비용 0 정책을 유지한다.
