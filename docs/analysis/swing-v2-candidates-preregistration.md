## 3. 측정

**Part A**: 진입 → 날짜별 평균 x_d → 평균, Newey-West t(lag 9), 달 평균 부호가 가설 방향인 달 비율. 구간별(H1·H2·H3)·시장별 값은 병기만.

**Part B**(E-2 와 같은 틀): 관측 = 유니버스 ∩ 피처 비결측. 날짜별 관측 < 30 인 날 제외.
- 날짜 IC = Spearman(피처, 10일 초과수익), 평균 IC 의 Newey-West t(lag 9).
- 날짜 스프레드 = 피처 상위 십분위 평균 − 하위 십분위 평균(십분위 = floor(n/10), 동점은 종목코드 순), 날짜 평균.
- 일자 안정성 = s × 날짜 스프레드 > 0 인 날 비율. 연도별 평균 IC(2024 · 2025).

## 4. 판정 규칙 (`auditV2.ts`)

### Part A — 홀드아웃 H1 ∪ H2 ∪ H3 합산
진입 < **100** 이면 판정 불가. 통과 = 아래 전부:
1. 평균 x_d 부호 = 가설 방향
2. (방향 × NW t) ≥ **2.24** (가설 2개 × 양측 Bonferroni, v1 과 같은 값)
3. 부호 맞는 달 비율 ≥ **55%**

### Part B — 발견 D (정·역 두 방향 모두 등록)
t 임계 = Φ⁻¹(1 − 0.05/(2·8)) = **2.73**. 통과 = 아래 4개 전부:
1. sign(평균 IC) = s 그리고 |NW t| ≥ 2.73
2. s × 스프레드 ≥ **0.28%**
3. 일자 안정성 ≥ **60%**
4. sign(2024 IC) = sign(2025 IC) = s

### Part B — 홀드아웃 (발견 통과 방향만, H1 ∪ H2 ∪ H3)
통과 = sign(평균 IC) = s · 일자 안정성 ≥ **55%** · s × 스프레드 > 0. 통과가 없으면 계산하지 않는다.

| 결과 | v2 반영 |

| C1 통과 | 체크리스트의 "제외(주의)"를 근거 있는 경고로 표시(과거 통계 병기) |
