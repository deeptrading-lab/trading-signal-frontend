# 단타·신호 자동매매 트랙 종료 기록 (2026-08-10)

> **결론: 종료.** `lib/signal/` 4축 기반 자동매매는 **왕복비용 0.28%를 넘는 예측력이 없음**이
> 네 번의 독립 검증으로 확정됐다. 더 이상의 파라미터 튜닝·판단 개선은 하지 않는다.

## 1. 무엇을 하려 했나

AI가 사람 개입 없이 장중 단타를 판단·집행하고, 그 **판단 신뢰도를 데이터로 올린다**.

## 2. 무엇이 증명됐나

| 검증 | 유니버스 | 타임프레임 | 표본 | 결과 |
|---|---|---|---|---|
| 분봉 감사 | 모멘텀 스크리닝 | 5·15·30·60분 | 20,354관측·27일 | 일자내 IC **−0.18**, 상위십분위 초과 **−0.27%** |
| 분봉 OOS | 동일 | 동일 | 49,087관측·21일 | 역방향 재현(IC −0.11, 86% 날 일치) |

## 3. 왜 실패했나 — 세 겹의 원인

1. **신호에 예측력이 없다.** 점수는 *과거* 추세를 정확히 측정하지만(D1 과거 −8.4% ↔ D10 +18.5%,
   완전 단조) *미래*는 따라오지 않는다(D1 +0.59% vs D10 +0.14%). 고득점 구간은 오히려 저조 —
   단기 반전(short-term reversal)과 부합.
2. **배리어가 실현 불가능했다.** TP 3×ATR 도달 14% vs SL 1.5×ATR 45%. 거리비 2:1인데 도달비
   1:3.2 — 60분 안에 목표에 못 간다. 손익비 2.0은 장부상 숫자였다.
3. **비용이 엣지보다 컸다.** 최선의 경우(역방향 60분)조차 우위 +0.36% vs 비용 0.28% = 마진 0.08%p.

> 한 줄 요약: **거꾸로 든 신호를, 실현 불가능한 배리어로, 비용을 못 넘는 크기로 매매했다.**

## 4. ★가장 값진 산출물 — 감사 방법론

신호는 실패했지만 **판별 방법**을 얻었다. 다음에 무엇을 시도하든 이건 계속 쓰인다.

### 방법론 3원칙 (반드시 지킬 것)

1. **횡단면 demean** — 풀링 통계는 날짜 효과로 오염된다.
   *실제 사례*: signalScore 풀링 IC **+0.052**(양수!)인데 일자내 IC **−0.176**, 양수인 날 19%.
   Simpson's paradox 때문에 "sigSpear 양수인데 왜 잃지?"를 몇 주 헤맸다.
2. **사전 등록** — 판정 기준을 **데이터 보기 전에 커밋**. 정·역 **대칭** 등록(한쪽만 걸면 반대쪽이
   좋게 나왔을 때 사후 분석이 된다 — 실제로 겪음). 결과 후 기준 수정 금지.
3. **경로 검증** — 종가 대 종가 평균은 배리어를 통과하지 못한다. 평균 +0.4%가 실현 −0.34%로
   뒤집힌 것이 그 증거.

### 보존 도구

| 파일 | 용도 |
|---|---|
| `scripts/signal/collect-{fixtures,oos,daily}.mts` | 분봉·일봉 데이터 수집(재실행 안전, 디스크 캐시) |
| `scripts/signal/edge-audit.mts` | 분봉 피처 IC·십분위·**시간대 교란 통제** |
| `scripts/signal/path-audit.mts` | 배리어 경로 시뮬(TP/SL 도달률·MFE/MAE·비용 차감 순수익) |
| `scripts/signal/daily-audit.mts` | 일봉 횡단면 IC·십분위 프로파일 |
| `scripts/intraday/today.mts` | 일일 실황·**비용 분해**·청산 사유 |
| `scripts/intraday/daily.mts`·`pool.mts` | provider별 채점·다일 풀링 |

**후보 입력 하나를 며칠이 아니라 한 시간에 판별**할 수 있다.

## 5. 재시도 금지 조건

아래는 **이미 검증되어 기각**됐다. 근거 없이 다시 시도하지 말 것.

| 시도 | 왜 안 되는가 |
|---|---|
| BUY 컷·밴드 튜닝 | 신호에 예측력이 없어 컷 위치와 무관 (65→58 실험 완료) |
| 프롬프트·판단 품질 개선 | I1~I3 적용 후에도 실현 음수. 오히려 A+ 정의가 역방향 신호를 더 충실히 따르게 함 |
| 손절 폭 확대 | 반사실 재시뮬에서 승률 24→38%인데 net −0.86%→**−1.44%** 악화 |
| 물타기·피라미딩 | 승률 착시, 기대값 음수 |
| 타임프레임 상향(일봉) | 본 감사로 기각 — KOSPI 전체에서도 IC 음수 |
| 역방향 매매 | OOS 재현은 됐으나 배리어 적용 시 −0.34%, 마진 0.08%p |

## 6. 다시 열어볼 조건

아래 중 하나가 충족되면 재검토할 가치가 있다.

- **새 정보원**이 오프라인 IC 감사를 통과할 때 — 체결 미시구조, 수급(외국인·기관·프로그램),
  공시·뉴스 이벤트, 업종 상대강도. 반드시 **구현 전에** `edge-audit` 로 먼저 거를 것.
- **비용 구조가 바뀔 때** — 거래세 인하, 수수료 면제 등. 현재 0.28% 중 제세금 0.15%가 고정 하한.
- 순서는 항상 **"입력 후보 → 오프라인 감사 → 통과분만 구현"**. 지금까지의
  "구현 → 라이브 → 손실 → 분석"을 반복하지 않는다.

## 7. 라이브 상태

- 페이퍼 트레이딩 코드·오토파일럿은 **그대로 남긴다**(관측 인프라로서 가치 있음). 다만 **추가 운영
  계획 없음**.
- 동결된 파라미터(컷 58·밴드·손절·fill 창)는 현 상태 유지 — 미운영이라 무해하다.
- 실제 코드 제거가 필요하면 별도 판단.
