- **방법 선례**: `signal-daily-audit-preregistration.md` / `daily-audit.mts` — 유니버스·유동성 필터·구간·횡단면 demean 을 그대로 따른다.

## 0. 등록 전에 이미 본 것 (공개)

수익률·IC·스프레드 등 결과 통계는 **아무것도 계산하지 않았다**. 다만 다음은 이 문서 작성 전에 봤다.

- KIS `investor_trade_by_stock_daily`(FHPTJ04160001) 를 005930 으로 3회 호출: 1콜 30거래일, `FID_INPUT_DATE_1` 을 과거로 옮기면 2023-11 까지 응답 → **2024-01 이전까지 수집 가능**, 구간 축소 불필요.
  응답의 `frgn_ntby_tr_pbmn`·`orgn_ntby_tr_pbmn` 은 백만원, `acml_tr_pbmn` 은 원 단위로 보였다(문서와 다름 — 아래 정의는 순위만 쓰므로 영향 없음).
- OpenDART `list.json`(corp_cls=Y, pblntf_ty=B) 2024-01~03 1페이지(100건)의 보고서명 분포 — 유상증자·자기주식취득/처분·신탁계약·전환사채 등이 분기당 수~십여 건.
- 일봉 캐시 829종목 중 2024-01~2026-08 어느 날이든 유동성 필터를 1회 이상 통과한 종목 수 = **655** (거래대금·종가만 사용, 수익률 미사용).

## 2. 후보 피처 (point-in-time — t 의 피처는 t 장마감까지 알 수 있는 정보만)

투자자별 확정치는 장 종료 후(15:40~) 산출되고 공시 접수 시각은 목록 API 에 없으므로, **수급·공시는 t 당일을 제외하고 t−1 까지**만 쓴다(보수적 1일 지연).

| # | 피처 | 정의 |
|---|---|---|
| F1 | 외국인 순매수 강도 | Σ_{k=1..5} 외국인 순매수대금(t−k) ÷ mean_{k=1..20} 거래대금(t−k). 거래대금 = 같은 KIS 응답의 `acml_tr_pbmn`. 25개 중 하나라도 결측이면 결측 |
| F2 | 기관 순매수 강도 | F1 과 동일, 기관계(`orgn`) |
| F3 | 외국인+기관 순매수 강도 | F1 과 동일, 분자 = 외국인 + 기관 |
| F4 | 업종 상대강도 | r20(종목) − median(r20(같은 업종의 다른 캐시 종목)). r20 = 종가 t ÷ 종가 t−20 − 1(각 종목 자기 캐시 기준 20봉 전). 업종 비교군은 유동성 무관 캐시 종목 중 t·t−20 종가가 있는 종목, **자기 제외 ≥ 3종목** 아니면 결측 |
| F5a | 유상증자 공시 | 플래그 1/0: 접수일이 (D[t−6], D[t−1]] 인 보고서 중 보고서명에 `유상증자결정`(유무상 포함) |
| F5b | 자사주취득 공시 | 동일 창, `자기주식취득결정` 또는 `자기주식취득신탁계약체결결정` |
| F5c | 자사주처분 공시 | 동일 창, `자기주식처분결정` |
| F5d | 전환사채 공시 | 동일 창, `전환사채권발행결정` |

- D[t−k] 는 그 종목 일봉 캐시의 k봉 전 날짜. 창 (D[t−6], D[t−1]] 은 직전 5거래일과 그 사이 휴일 포함, t 당일 제외.
- F5 공통: 보고서명이 `[` 로 시작하는 것(`[기재정정]`·`[첨부정정]`·`[연장결정]`·`[발행조건확정]` 등)은 정정·부속이라 **제외**. 공백은 제거 후 매칭.
- 위 외의 공시 유형은 보지 않는다. 피처를 결과 본 뒤 추가·변경하지 않는다.

## 3. 측정 (피처마다, 구간마다)

관측 = (날짜 t, 종목) 중 유동성 통과 + 피처 비결측 + t+10 종가 존재. 날짜별 관측 < 30 인 날은 그 피처에서 제외.

| 지표 | 정의 |
|---|---|
| 날짜 IC | 날짜별 Spearman(피처, 10일 초과수익), 동점은 평균 순위 (`lib/server/scorecard/directionDiagnosis.ts` `spearman`). 이진 피처는 그날 플래그 1 이 ≥ 1건 있는 날만 |
| 평균 IC · t | 날짜 IC 시계열의 평균과 t. **10일 겹침 수익률이라 IC 가 자기상관 → Newey-West(Bartlett, lag 9) 표준오차로 t 를 계산**(판정용). naive t 는 병기만 |
| 스프레드 | 연속 피처: 날짜별 (상위 십분위 평균 초과수익 − 하위 십분위 평균), 십분위 크기 = floor(n/10). 이진 피처: 날짜별 (플래그 1 평균 − 플래그 0 평균). 날짜 평균 |
| 일자 안정성 | 날짜별 스프레드가 **예상 부호**인 날의 비율 |
| 연도별 부호 | 2024 / 2025 각각의 평균 IC 부호 |
| 4축 중복 | 날짜별 Spearman(피처, `evaluateSignal(...).score`) 평균. warmup 130봉이라 2024 중반 이후 관측만 |

### 이진 피처 표본 부족

고유 이벤트(종목 × 접수번호, 해당 구간 유동성 관측에 1회 이상 등장) 가 **발견 < 30 이면 판정 불가**, 홀드아웃 < 10 이면 홀드아웃 판정 불가.

## 4. 판정 규칙 (정·역 대칭 — 둘 다 등록)

방향 s ∈ {정(+1): 높을수록 좋다, 역(−1): 낮을수록 좋다}. 같은 피처가 두 방향을 동시에 통과할 수는 없다(IC 부호로 갈림).

### 다중비교 (Bonferroni)

후보 8개(F1~F4, F5a~d) × 양측 검정. t 임계 = Φ⁻¹(1 − 0.05/(2·8)) = **2.73** (기본 2.0 에서 상향). 정·역 방향은 같은 양측 검정의 두 꼬리라 추가 분할하지 않는다.

### 발견 통과 — 아래 4개 전부

1. sign(평균 IC) = s **그리고** |NW t| ≥ **2.73**
2. s × 스프레드 ≥ **0.28%**
3. 일자 안정성(s × 날짜 스프레드 > 0 인 날 비율) ≥ **60%**
4. sign(2024 평균 IC) = sign(2025 평균 IC) = s

### 홀드아웃 통과 (발견 통과분만) — 아래 3개 전부

1. sign(평균 IC) = s
2. 일자 안정성 ≥ **55%**
3. s × 스프레드 > 0

### 최종

| 발견 | 홀드아웃 | 결론 |
|---|---|---|
| 통과 | 통과 | **통과 피처** — 4축 중복 상관 병기, 경로 검증·PM 주입 여부는 별도 논의 |
| 통과 | 불통과 | 불통과(발견 구간 과적합) |
| 불통과 | (계산 안 함) | 불통과 |
| 판정 불가 | — | 판정 불가 |

모든 피처가 불통과·판정 불가면 PRD §3-3 중단 조건(E-1·E-2 모두 불통과 → OQ-8 결론 확정)의 E-2 쪽 입력이 된다. **같은 피처를 창 길이·정규화만 바꿔 재시도하지 않는다.**

## 5. 수집 규칙

- KIS: 조회 전용 TR 만(주문 API 금지), 호출 간 ≥ 200ms, transient(5xx·네트워크·초당 제한) 1회 재시도, **KIS 야간 점검 시간대(21:45~07:00 KST) 진입 시 즉시 중단** → 재실행 시 캐시 있는 종목은 스킵(이어받기).
- 캐시: `scripts/signal/__flow__/` (gitignore). DB 쓰기 없음.
- 수집 결측(빈 응답·실패)은 결과 문서에 종목 수·기간으로 기재한다.

## 6. 알려진 한계 (미리 기록)

- **생존 편향**: 유니버스는 현재 상장 KOSPI(`symbols.json`). 결과가 낙관 쪽으로 기운다.
- **업종 분류 룩어헤드**: 업종명은 2026-10 현재값. 기간 중 업종 변경 종목은 소수로 보고 무시.
- **수급 KRX 한정**: `J` 시장코드라 NXT 체결분 미포함. 분모도 같은 응답의 KRX 거래대금이라 비율은 일관.
- **공시 시각 미상**: 1일 지연으로 처리 — 당일 장중 공시 반응은 측정하지 않는다(보수적).
- 비용 0.28% 고정, 수정주가는 데이터 제공자 기준.

## 7. 불변 조건

- 결과 계산 후 이 문서 수정 금지. 기준을 바꿔야 하면 **새 사전 등록 문서**를 쓰고 결과 문서에 그 사실을 남긴다.
- 사전 등록과 다르게 한 점은 결과 문서에 별도 절로 기재한다.
