## 2. 규칙 (= 동결 코드, `lib/swing/rulebook.ts` RULEBOOK)

- **제외**: 데이터 부족 · 유동성 · 거래정지(최근 5봉 거래량 0) · 스팩·리츠 · 고변동(ATR14% ≥ 시장별 경계 — §0-1 의 발견 구간 67퍼센타일) · 과열(r20 ≥ 20% 또는 RSI14 ≥ 75) · 자금조달·위험 공시(20거래일 창, 정정 제외).
- **A 수급**: A1 S_개인 ≤ −0.02N, A2 S_외국인 ≥ +0.02N, A3 S_기관 ≥ +0.02N ∧ S_사모 < 0.5·S_기관. S_g(N) = N일 순매수 합(원) ÷ 수급 거래대금 20일 평균.
- **B**: 손절 근거가 매물대(비중 ≥ 6%) 또는 쌍바닥이고 손익비 ≥ 1.5.
- **C**: 국면(과열 → 바닥권 → 하락추세 → 상승추세 → 횡보 → 혼조 순 판정)이 과열·하락추세 아님.
- **D**: (MACD 골든크로스 최근 5봉 ∨ SMA5×20 골든크로스 최근 5봉) ∧ 45 ≤ RSI14 ≤ 70.
- **E**: 쌍바닥(두 번째 바닥 t−10~t−3, 첫 바닥 그 전 10~60봉, 가격차 ≤ 1 ATR, 반등 ≥ 2 ATR, 이후 이탈 없음) ∧ MACD 상승 다이버전스.
- **매수 후보** = 제외 없음 ∧ A ∧ C ∧ B ∧ (D ∨ E).

## 4. 판정 규칙 (`lib/swing/audit.ts`)

### 다중비교
변형 2개 × 양측 → t 임계 = Φ⁻¹(1 − 0.05/4) = **2.24**.

### 발견 D — 판정 불가 조건
진입 < **300** 또는 진입일 < **150** → **판정 불가**.

### 발견 D — 통과 = 아래 5개 전부
1. 평균 x_d ≥ **+0.28%**
2. NW t ≥ **2.24**
3. 월 안정성 ≥ **60%**
4. 2024 평균 > 0
5. 2025 평균 > 0

두 변형이 모두 통과하면 V1 을 쓴다. 하나만 통과하면 그것을 쓴다. 홀드아웃은 쓰기로 한 변형 하나만 계산한다.

### 홀드아웃(H1 ∪ H2 ∪ H3 합산) — 통과 = 아래 전부
진입 < **100** 이면 판정 불가. 평균 x_d > 0 · 월 안정성 ≥ **55%**. 구간별 값은 병기만.

### 계획 경로 — 통과 = 아래 전부
발견 평균 y_d > 0 · 발견 월 안정성(y) ≥ **55%** · (홀드아웃을 계산했다면) 홀드아웃 평균 y_d > 0.

### 결정표 (`releaseMode`)

| 발견 | 홀드아웃 | 계획 경로 | 출시 형태 |
|---|---|---|---|
| 통과 | 통과 | 통과 | 등급(매수 후보) + 진입/손절/목표 |
| 통과 | 통과 | 미달 | 등급 + 가격은 "참고 레벨" |
| 통과 | 미달 | — | 체크리스트 |
| 미달 또는 판정 불가 | 계산 안 함 | — | 체크리스트 |

**시장별 규칙**: 발견 구간 시장별 평균 x_d 가 음(−)인 시장은 위 결과와 무관하게 그 시장만 체크리스트.

### 과거 통계(`audit.mts stats`, 결과 문서 커밋 뒤)
쓰기로 한 변형(둘 다 미달이면 V1)으로 전 구간 셀(등급·조건·국면 × 시장 × 연도, 진입 단위)의 n · 10일 상승 비율(주 클러스터 부트스트랩 95% 구간, 1,000회, 시드 20261031) · 평균/중앙 r10 · 평균 초과수익 · 같은 날 U 기준선 · 계획 결과 비율을 `lib/swing/stats-v1.json` 에 쓴다. n < 30 셀은 숨김 표시. 파일은 RULEBOOK 을 통째로 품고 테스트가 현재 RULEBOOK 과의 일치를 확인한다.
