## 2. 부호·구현 검증 (강한 주장이라 별도 확인)

버그로 인한 오판이 아님을 확인했다.

| 십분위 | 평균 점수 | **←과거 20일** | 미래 20일→ |
|---|---|---|---|
| D1 | 30.9 | **−8.42%** | +0.59% |
| D5 | 46.4 | −2.78% | +1.16% |
| D10 | 71.6 | **+18.47%** | +0.14% |

- 점수는 **과거 추세를 정확히 측정**한다(D1 −8.4% ↔ D10 +18.5%, 완전 단조). 부호 반전 버그 없음.
- `action` 매핑도 정상: BUY 평균 67.4점 / HOLD 50.0 / SELL 34.9.
- 그런데 **미래 수익률은 점수를 따라가지 않는다**(D1 +0.59% vs D10 +0.14%).

→ **"과거 추세는 정확히 재는데, 그 추세가 미래를 예측하지 않는다."** 이것이 4축의 실체다.
D8~D10 의 저조는 **단기 반전(short-term reversal)** 로 알려진 현상과 부합한다.

특유의 되돌림이었고, 일봉으로 확장되지 않았다.

## 4. 남은 선택지

| | 내용 | 비고 |
|---|---|---|
| **C. 새 입력 탐색** | 가격 파생 피처를 버리고 다른 정보원 — 체결 미시구조, 수급(외국인·기관·프로그램), 공시·뉴스 이벤트, 업종 상대강도 | 유일하게 남은 "자동매매 유지" 경로. 성공 미지수 |
| **D. 트랙 종료** | 단타·신호 자동매매를 접고, 지금까지 구축한 관측·감사 인프라만 자산으로 보존 | 정직한 손절 |

**권고**: C 로 가더라도 **먼저 이번 감사 방법론을 그대로 적용**해 후보 입력을 싸게 걸러낸다.
즉 "구현 → 라이브 → 손실 → 분석"이 아니라 **"입력 후보 → 오프라인 IC 감사 → 통과분만 구현"**.
이번 사이클에서 얻은 가장 큰 자산은 신호가 아니라 **이 감사 파이프라인**이다.
