- **PRD**: `docs/prd/ai-direction-quality.md` §3-1
- **등록일**: 2026-10-18 (결과 문서보다 먼저 커밋한다. 이 문서는 첫 커밋 이후 수정하지 않는다)
- **대상 데이터**: `signal_scorecard` 중 `w2_status ∈ {hit, miss, flat}` 이고 `w2_return_pct` 가 유한한 행 (2026-10-18 스냅샷, 진입 2026-06-19 ~ 09-02). 판정 본문은 `ai_analysis_decisions`.

## 0. 등록 전에 이미 본 것 (공개)

가설별 통계는 아직 계산하지 않았다. 다만 다음 값은 이 문서 작성 전에 이미 봤다.

- 게이트 수치: 강세군 n=20 적중 40% (찍기 45%), 약세군 n=101 적중 57% (찍기 55%).
- verdict 분포: UNDERWEIGHT 79 / REDUCE 22 / OVERWEIGHT 20 / HOLD 9 / BUY·SELL 0.
- REDUCE 22건의 2주 평균 수익률 +8.5%.
- 월별 분석 건수 43 / 79 / 7 / 1 / 0, 7/30 진입분 KOSPI 1일 수익률 +17.9% (실제 급반등).
- 프롬프트 `app/api/stock/ai-analysis/route.ts:301` 이 UNDERWEIGHT 를 "관망(HOLD/UNDERWEIGHT)"으로 묶는다는 사실.

## 1. 공통 정의

| 항목 | 정의 |
|---|---|
| 방향 점수 d | BUY·OVERWEIGHT = +1, HOLD = 0, UNDERWEIGHT·REDUCE·SELL = −1 |
| 강세군·약세군 | d = +1 / d = −1 (게이트 `BULL_VERDICTS`·`BEAR_VERDICTS` 와 동일) |
| 진입 주 | `entry_date` 의 ISO 주 (월요일 시작) |
| 절대 적중 | 강세군 `w2_return_pct > 0`, 약세군 `< 0` (게이트와 동일) |
| 초과 적중 | 강세군 `w2_excess_return_pct > 0`, 약세군 `< 0` |
| 직전 국면 | 진입일 **이전** 10영업일 KOSPI 수익률 (KIS 업종지수 일봉, `lib/api/kis/index-chart.ts`). AI 가 결정 시점에 알 수 있던 정보만 쓴다 |
| preReturn20d | 진입일 종가 ÷ 20영업일 전 종가 − 1 (종목 일봉: `scripts/signal/__daily__` 캐시 우선, 없으면 KIS 일봉) |
| 표본 부족 | 비교 대상 집단 중 하나라도 n < 15 면 해당 비교는 **판정 불가** |

판정 라벨은 `지지` / `기각` / `판정 불가` 셋 중 하나만 쓴다.

## 2. 가설별 측정과 판정 규칙

### H-A1 등급 의미 비대칭 (UNDERWEIGHT = 관망)
- **1차 (텍스트)**: `ai_analysis_decisions` 중 verdict = UNDERWEIGHT 인 판정의 `holder_strategy` 를 분류한다.
  - "유지/관망" = `/(유지|보유|관망|홀드|지켜)/` 매칭 **그리고** `/(매도|축소|줄이|정리|청산|비중\s*감소)/` 미매칭.
  - UW 판정 본문 ≥ 10건일 때: 유지/관망 비율 ≥ 60% → **지지**, ≤ 30% → **기각**, 그 사이 → **판정 불가**. 10건 미만 → **판정 불가**.
- **2차 (수익률, 참고)**: HOLD 행 n < 20 이면 UW·HOLD 수익률 비교는 기재만 하고 판정에 쓰지 않는다 (유의하지 않음 ≠ 같음).

### H-A2 진입 장벽 비대칭 (단계별 약세 이동)
- 단계별 판정(stageStances)은 Phase 0 이후 행에만 있다. 기존 130행으로는 측정할 수 없다 → **판정 불가** (Phase 0 배선 후 재측정).

### H-A3 국면 편중 (판정이 국면을 따라간다)
- 행을 직전 국면 값으로 정렬해 3분위로 나눈다 (행 기준 등분).
- 강세군 비율(d = +1 비율) 차이 = 상위 분위(직전 상승) − 하위 분위(직전 하락).
  - ≥ 15%p → **지지**, < 5%p → **기각**, 그 사이 → **판정 불가**. 분위당 n < 15 → **판정 불가**.

### H-A4 레짐 veto 부활 (#375, 2026-07-29)
- `decided_at < 2026-07-29` 집단의 강세군 비율을 잰다.
  - 그 비율 ≤ 20% (이미 쏠림) → 기존 쏠림에 대해 **기각** (레짐 veto 가 무력하던 때도 쏠렸다).
  - > 20% 이고 이후 집단(n ≥ 15)의 강세군 비율이 10%p 이상 낮음 → **지지**. 그 외 → **판정 불가**.
- 향후 쏠림 요인 여부는 Phase 0 의 `diagnostics.signalRegime` 로 재측정 (이번 판정 범위 밖).

### H-A5 #352 PM 프롬프트 (2026-07-13) 효과
- 비교: `decided_at < 2026-07-13` vs `2026-07-13 ≤ decided_at < 2026-07-29` (#375 혼입 차단).
  - 이후 집단 n < 15 → **판정 불가**.
  - 강세군 비율이 10%p 이상 상승 → **지지**, 상승 < 3%p 또는 하락 → **기각**, 그 사이 → **판정 불가**.

### H-B1 방향 예측력 부재
- 각 행의 `w2_excess_return_pct` 에서 같은 진입 주 평균을 뺀다 (횡단면 demean).
- d 와 demean 값의 Spearman 순위상관 ρ.
- 95% 구간: 진입 주 단위 클러스터 부트스트랩 2,000회 (시드 20261018).
  - 구간이 0 을 포함 → **지지** (예측력 없음). 구간 전체 > 0 → **기각**. 구간 전체 < 0 → **지지** (역예측 병기).
  - 고유 진입 주 < 6 → **판정 불가**.
- 병기 (OQ-6, 판정 무관): 진입 주 기준 찍기 점수로 계산한 게이트 수치.

### H-B2 베타 착시
- 강세군 + 약세군 행 전체에서 절대 적중률 − 초과 적중률.
  - ≥ 10%p → **지지**, < 3%p → **기각**, 그 사이 → **판정 불가**.

### H-B3 단기 반전 역행
- 조건 1: 약세군 preReturn20d 중앙값 − 비약세군(강세군 + HOLD) 중앙값 ≤ −5%p.
- 조건 2: preReturn20d 하위 3분위 행 중 약세군의 절대 적중률 < 그 분위 전체의 하락 비율 (분위 내 찍기).
- 둘 다 만족 → **지지**. 조건 1 의 차이가 > −2%p → **기각**. 그 외 → **판정 불가**. 하위 분위 약세군 n < 15 → **판정 불가**.

### H-C1 표본 부족 (측정만)
- 월별·소스별 분석 건수, 고유 종목 수, 고유 진입 주 수, 종목 중복 재분석 수, 강세군·약세군 각 진입 주 분포. 판정 대상 가설이 아니므로 결과 표에는 "판정 불가 (측정 항목)"으로 기재한다 (PRD AC-1.5 의 9행 형식 유지).
