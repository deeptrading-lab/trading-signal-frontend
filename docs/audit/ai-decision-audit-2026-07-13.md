## Part C — 개선사항

### C-1. 채점(즉시, 코드 픽스)
1. 지수 필드명 픽스 + 청크 60일 + 스키마 가드 (Part A 상세). **이거 하나로 19일치 pending이 다음 cron에 자동 소급 채점됨.**
2. 관측성: scored=0 연속 시 감지 수단 마련(cron-status 노출 또는 주기 점검 절차).

### C-2. 판정 생성(분석 프롬프트/구조)
1. **verdict 분포 붕괴**: 34/39 약세, BUY/SELL 0, confidence 전원 MEDIUM, horizon 전원 중기. 단타 judge의 100% HOLD와 동일 계열 문제(판정 다양성 소실). confidence가 전부 MEDIUM이면 캘리브레이션 표시 기능 자체가 무의미해짐.
2. **약세 콜의 target/stop 세맨틱 모순 (구조 결함, 최우선)**: 약세 34건 중 33건이 target·stop 모두 음수. stop이 target보다 깊은 역전(S-Oil -14/-16), 동일값(삼성전자 -7.4/-7.4), 1%p 간격(DB하이텍) 등 — 하락 적중 시 목표와 손절이 같은 날 동시 터치(19건)되고, **상방 역주행 시 발동할 무효화 라인이 전무**. 약세 콜의 stop은 상방(+%) "테제 무효화 라인"으로 재정의해야 함(스키마·프롬프트·UI 연쇄 수정 필요).
3. **자기 나열 반대신호 기각 패턴**: RSI 과매도·공매도 누적·외국인 연속 순매수·수주 촉매를 keyStrengths/keyRisks에 적어놓고 verdict는 반대로 — 종합(PM) 단계에서 반대신호 명시 가중 규칙 필요.
4. **베타/알파 미구분**: 분석 컨텍스트에 지수 국면(레짐) 대비 상대 판단을 명시적으로 요구 — "시장이 -10% 빠질 때 이 종목은 더/덜 빠질 이유"를 강제.
5. **박스권 헤지 문구 남발**: 단기전망 대다수가 "박스권 등락"으로 수렴하나 실제로는 박스 이탈 빈발(한미 -24%, 기아 +18%) — 검증 가능한 조건부 전망 강제.

### C-3. 채점 로직 고도화(phase-2, 후순위)
- target/stop 터치 채점 도입은 **C-2-2 세맨틱 정리가 선행돼야 의미 있음** (현 데이터로는 동시 터치 19건이라 판별력 없음).
- 분석 시 base_price(실시간가)와 채점 entry_close(asOf 봉 종가) 소스 차이, 토스/KIS 종가 차이(±2% 임계 근처) 인지.
