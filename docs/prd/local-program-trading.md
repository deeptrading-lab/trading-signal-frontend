# 로컬 프로그램 자동매매

## 1. 문제
AI 반복 판단 대신 코드 규칙으로 매매하고 AI는 거래 결과를 검토한다.
## 2. 사용자
로컬에서 한투 연동 전 동작을 검증하는 운용자.
## 3. 범위
/intraday 상단 UI, 독립 Node 워커, 합성 시세, 가상 계좌 1천만원, JSON 영속화, 복기 Markdown. 실제 KIS 호출과 AI 자동 분석/파라미터 변경 제외.
## 4. 동작
2초=가상 1분. 3분 고가 0.1% 돌파+거래량 1.5배, 스프레드 15bps 이하, 시세 5초 이하. 09:10~15:00 진입. 최대 2종목, 종목당 20%, 비용 포함 거래 위험 예산 0.25%. 손절 1%, 익절 2%, 일일 자산 손실 2% 잠금, 15:20 청산. 재진입 10분 대기. 갭 손실은 제한 초과 가능.
## 5. 수용 기준
시작/매수중지/청산, 중복 진입 금지, 현금 음수 금지, stale/halt 차단, 중지 중 위험 관리, 마감/킬, 재시작 시 매수 중지 복원, 화면 종료와 무관한 운용, 복기 파일 저장.
## 6. 운영
npm run program:worker 및 npm run dev. 고정 127.0.0.1:4318 워커, /api/program-trading BFF. development에서만 허용. .local/program-trading/state.json과 review.md, 워커 단일 포트 소유, 직렬 명령/틱, atomic rename.
## 7. 위험
합성 즉시 전량체결 모델은 수익성 증거가 아니다. 한투 REST 주문응답은 실제 체결과 다르므로 실연동 전 접수/부분체결/거절/조회 대사/멱등성 필수. 종료 후 새 실험은 워커 종료→로컬 상태 별도 보관→재실행. 현재 단일 일자 리플레이.
## 8. 영향 분석
기존 AI 가이드와 병존하는 독립 패널. 기존 AI 판단·DB·KIS 토큰 사용 안 함. Next serverless에서 워커 실행 안 함.
## 9. OPEN QUESTION
실제 계좌 유형·매매 시장·위험 한도는 연결 전 결정. 권고: KIS 모의투자 서버→과거 데이터 미사용 기간 검증→사람 승인 후 실계좌. AI는 원장으로 제안만 하고 적용은 검토·테스트로 승인.

## 2026-10-27 변경: 화면 분리·후보 목록 제한
- AI 단타 가이드 / 프로그램 자동매매 탭으로 구분. 키보드 좌우/Home/End 및 ARIA 연결 지원. 탭 전환 자체는 운용 명령을 전송하지 않음.
- 고정 예시 종목 제거. 가이드 추천과 같은 KIS 거래량 순위(volume, 보통주 14개), 외국인 순매수 상위 10개, 기관 순매수 상위 10개를 union. ticker 중복 제거, 출처 배지 표시.
- 랭킹 공급자 함수는 가이드 BFF와 동일. 자동매매는 표시용 mock/mock-timeout fallback을 사용하지 않음. 미설정·실패·빈 목록이면 실행 금지.
- 워커 시작·시작 명령·실행 중 60초마다 서버에서 후보 조회. 시작 명령에서는 반드시 재검증. 120초 만료. 일부 조회가 실패해도 이번 스냅샷 전체를 unavailable로 처리하여 시작/신규매수 차단.
- UI 버튼뿐 아니라 command 및 step에서도 후보 유효성과 membership 검사. 실패 시 이전 후보 목록으로 매수하지 않음. 실패 후 목록 회복만으로 자동 재시작하지 않음.
- 시세·체결은 기존 합성 모델 유지. candidate 편입 시 실제 가격을 합성 시세의 기준가로 사용하고, 운용 중 동일 ticker 기준가는 고정. 후보에서 빠진 보유분도 위험 관리 유지.
- 후보 없음으로 확인될 경우 워커는 실행 중지 상태를 유지한다. 목록이 회복되어도 명시적 시작 전까지 중지한다.

## 2026-10-29 변경: 후보 갱신과 매매 점검 분리
- 한투 실제 후보 조회를 별도 60초 타이머에서 실행. 외부 네트워크 조회는 매매 대기열을 점유하지 않고 스냅샷 적용만 직렬화한다.
- 동시 갱신 요청 합침, 조회 중 더 최근 중지/청산 명령이 들어오면 이전 시작 요청 취소.
- 후보 실패/만료 시 신규 매수 중지, 보유 위험관리·회복 후 수동 시작 정책 유지.
- 실제 연결 확인 및 확장에 필요한 설정·후속 작업은 `docs/program-trading/integration.md` 참조.
