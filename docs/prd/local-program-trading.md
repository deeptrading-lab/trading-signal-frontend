# 로컬 토스 모의매매

## 1. 문제
실제 주문 없이 국내주식 자동매매 기준과 운용 흐름을 연습할 수 있어야 한다.

## 2. 사용자
본인 컴퓨터에서 토스 Open API 시세 키로 전략을 연습하는 사용자.

## 3. 범위
로컬 `/program-trading`에 토스 시세 기반 가상 계좌와 매매 시작·종료, 가상 보유·손익·원장을 제공한다. 초기 자금은 1,000만 원이다.

## 4. 동작
- `.env.local`의 토스 클라이언트 ID·시크릿을 사용한다. AI 단타의 실제 수급 상위·거래량 상위 목록을 공유하고 중복을 제거한다. 추천 조회 실패 시 신규 매수를 중지한다.
- `npm run program:dev`로 루프백 개발 서버를 시작한다. 서버 내부에서 단일 엔진이 명령과 틱을 직렬 처리한다.
- 유효한 후보와 정규장 정보를 확인하고 KST 09:10~15:00 미만에 시작한다. 최근 체결·호가 5초 이내, 직전 3분봉과 진행분 거래량 등 조건을 만족하면 가상 체결을 기록한다.
- 종료 요청, 손실 제한, 마감 시각 순으로 청산 조건을 확인한다. 시세가 유효해져 보유가 모두 정리되면 종료 자산과 수익률을 확정한다.
- 로컬 파일에 상태와 가상 체결 원장을 저장한다. 서버 재시작 시 신규 매수를 멈춘 상태로 복원한다.
- 거래 종료 후 **새 세션 열기**를 누르면 기존 상태와 원장, 복기를 자동으로 보관하고 가상 자금 1,000만 원으로 시작을 대기한다.
- **세션 결과 보기**에서 종료된 현재 세션과 보관된 세션의 자산, 손익, 수익률, 청산 건수와 복기 항목을 확인한다.
- 세션 결과는 원장 대조 결과, 확인된 문제, 기록 부족으로 판단을 보류한 항목, 전략 개선 가설과 근거를 표시한다.

## 5. 수용 기준
1. 토스 키와 앱의 기존 순위 연동을 갖춘 로컬 환경에서 로그인 없이 상태 조회와 시작 명령을 사용할 수 있다.
2. 휴장·장외와 교차 출처 시작 요청을 거부한다.
3. 유효한 시세에서만 가상 체결하며, 후보 만료 시 신규 매수를 중지한다.
4. 종료 후 가상 보유가 0일 때 복기를 생성한다.

## 6. 저장과 접근
`.local/program-trading/toss-paper/`에 가상 거래 기록을 보관한다. 루프백 개발 서버와 동일 출처 변경 요청만 허용한다.
현재 세션과 보관 세션의 `review.json`을 합쳐 최신 100건까지 보관한다. 한도를 넘으면 오래된 결과 JSON부터 제거하며 원장과 상태 파일은 보관한다.

## 7. 운영
가상 체결은 비용·슬리피지 가정을 사용한다. 설정과 운용 절차는 [시작 가이드](../program-trading/getting-started.md)에 있다.

## 8. 영향 분석
자동매매 BFF는 로컬 엔진을 직접 호출한다. 앱의 다른 메뉴는 각자의 기존 접근 규칙을 사용한다.

## 9. OPEN QUESTION
계정별 설정과 원장 저장은 로컬 사용 결과를 검토한 뒤 별도 범위로 결정한다.
