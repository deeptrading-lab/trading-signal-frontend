# PRD — 신호 토대 감사 (signal-edge-audit)

작성 2026-08-07 · 상태: 계획 · 브랜치 `feature/hylee/signal-edge-audit`

## 1. 배경 — 왜 판단층이 아니라 신호층인가

Week1 개선(I1~I3·밴드 재배치·컷 58·관측 창)은 **구조적 결함은 고쳤으나 엣지는 만들지 못했다**.

| 하영 누적 (4거래일·27 라운드트립) | |
|---|---|
| 실현 손익 | −195,602원 |
| ├ 가격손익 | **−119,891원** (회전 대비 **−0.221%**) |
| └ 거래비용 | −75,711원 (회전 대비 0.140%) |
| 실현 승률 | 5/27 (**19%**) — 손익분기 33% 필요 |

**핵심**: 비용을 0으로 만들어도 진다(가격손익 자체가 −0.221%). 컷·밴드·프롬프트로 고칠 수 있는 층이 아니다.

> ⚠️ 이전 진단 정정 — 7/30에 "손실의 74%가 비용"이라 했으나 이는 **하영·찬민 데이터를 섞어 계산한 오류**였다. 하영 단독 누적은 가격손익 손실(−119,891)이 비용 손실(−75,711)보다 크다.

이는 2모델 교차검증 결론(claude·codex 둘 다 손익분기 미달 = 모델이 아니라 **접근법** 문제)과 합류한다.

## 2. 아직 한 번도 measure 하지 않은 것

기존 자산 `lib/signal/backtest/__live__/intradayDiagnostic.test.ts` 는 **전략 레벨**만 스윕한다 — 비용·레짐 on/off·진입 모드·배리어 종류·graded 축 A/B. 즉 *"이 룰 조합이 돈이 되나"*.

**그 아래층은 비어 있다**: *"입력 피처 자체에 예측력이 있나"*. 4축(추세·모멘텀·거래량·변동성)·VWAP·구조 레벨이 **미래 수익률과 상관이 있는지**, 있다면 **왕복비용 0.28%를 넘는 크기인지** 를 잰 적이 없다.

엣지 없는 피처 위에 판단층을 아무리 정교하게 쌓아도 결과는 같다. **감사 없이 재설계부터 하지 않는다.**

## 3. 풀어야 할 역설 (이 감사의 1차 목표)

실측에 모순이 있다. **sigSpear 가 양수였는데 돈은 잃었다.**

- 7/21 sigSpear **+0.163**, 7/22 **+0.258** — signalScore 가 +30분 수익률과 양의 순위상관
- 그런데 같은 기간 실현 손익은 음수, 승률 19%

가능한 설명 4가지를 **분해해서 가려낸다**:

| # | 가설 | 검증 방법 |
|---|---|---|
| H1 | **크기 부족** — 상관은 양이나 거래 가능한 스프레드가 비용 미만 | 상위 십분위 평균 수익률 vs 0.28% |
| H2 | **표본 부풀림** — 겹치는 윈도우·자기상관으로 IC 가 과대 | 겹치지 않는 샘플·일자별 IC 분포 |
| H3 | **경로 의존** — 평균 드리프트는 +여도 손절이 먼저 맞음 | 진입별 MFE/MAE 분포, 손절 도달 선행률 |
| H4 | **선택 편향** — 실제 진입은 전체 틱의 편향된 부분집합 | 전체 틱 IC vs 실제 진입 틱 IC 대조 |

**H3 가 유력**하다(청산 사유 손절 8 : 익절 2, 손절 우세). 하지만 손절 확대는 이미 기각됐으므로(net 악화), 그렇다면 문제는 **손절 폭이 아니라 진입 타이밍**이라는 뜻이 된다.

## 4. 범위 (Phase 1 — 감사만, 재설계 아님)

**하는 것**
- 실제 배포 유니버스(오토파일럿이 고른 종목)의 1분봉으로 피처 × 호라이즌 예측력 측정
- 피처별: 4축 개별 · signalScore · 동의도 · regime · VWAP 이격 · 거래량 z · 구조 RRR
- 호라이즌: 5 / 15 / 30 / 60분
- 지표: **IC**(Spearman, 일자별 분포 포함) · **십분위 스프레드** · **상위 십분위 평균 수익률** · **MFE/MAE 경로 분포**
- 비용선(0.28%)을 모든 표에 같이 그린다

**안 하는 것**
- 새 피처 발명, 모델 학습, 프롬프트·컷 수정 — Phase 1 결과 전에는 **코드 동결**
- 라이브 동작 변경 (감사는 전부 오프라인, 읽기 전용)

## 5. ★사전 등록 판정 기준 (결과 보고 나서 바꾸지 않는다)

Phase 1 종료 시 아래로 **기계적으로** 판정한다.

| 판정 | 조건 | 다음 행동 |
|---|---|---|
| **GO** | 어떤 (피처 × 호라이즌)이 **상위 십분위 평균 수익률 > 0.28%** 이고, 일자별 IC 가 **과반의 날에 같은 부호** | 그 피처만 남기고 신호 재설계. 나머지 축은 버린다 |
| **CONDITIONAL** | 상위 십분위 > 0.28% 이나 일자별 부호가 불안정 | 표본 확대(더 많은 날·종목) 후 재판정. 그때까지 라이브 변경 없음 |
| **NO-GO** | 어떤 조합도 상위 십분위 ≤ 0.28% | **현 입력 집합으로 분봉 자동매매는 불가**를 결론으로 확정. 새 입력(수급·틱데이터·외부 신호)을 찾거나 decision-support(사람 집행)로 피벗 |

**NO-GO 도 유효한 성과다.** "안 되는 걸 계속 시도하지 않게 되는 것"이 이 감사의 값어치다.

4. **Phase 1c** — 전체 틱 vs 실제 진입 틱 대조 (H4 판정)
5. **판정** — §5 표대로 기계적으로. 리포트 작성

## 9. OPEN QUESTION

1. **유니버스 범위** — 오토파일럿 선정 종목(모멘텀 상위)만 볼지, 대형주까지 포함할지.
   → *PM 권고: 선정 종목 우선.* 감사는 **실제 배포 분포**에서 해야 의미가 있다. 대형주는 대조군으로만.
2. **기간** — 현재 실매매 4일뿐이나 픽스처는 과거로 더 확장 가능(KIS 최근 며칠 제약 있음).
   → *PM 권고: 분봉 조회 가능한 최대 과거 + 종목 수로 표본을 벌린다.* 일자 부족은 종목 수로 보완.
3. **NO-GO 시 다음 입력 후보** — 체결강도/호가(이미 I3로 써봄·초단위 노이즈)·프로그램매매·업종 상대강도 등.
   → *PM 권고: Phase 1 결과 전엔 논의하지 않는다.* 먼저 현 입력을 확실히 사망 선고할 것.
