## 1. 배경 / 문제

종목 "AI 종합분석"은 에이전트 12개(분석가 4 → 강세·약세 토론 → 리서치 매니저 → 트레이더 → 리스크 3 → PM)가 최종 판정까지 내린다.

| 문제 | 근거 |
|---|---|
| 방향 예측력이 없다 | 다섯 번의 독립 감사가 같은 결론(`docs/analysis/*`). 2주 기조 ρ = −0.003 |
| 판정이 보수적으로 쏠린다 | UNDERWEIGHT 61%, BUY·SELL 0건(130행) |
| 산출물이 일정하지 않다 | 같은 종목도 돌릴 때마다 판정·가격이 달라진다 |
| 느리고 prod 에서 바로 못 돈다 | PM 상한 900초, prod 요청은 로컬 PC 워커가 처리 |

사용자(스윙, 보유 1~2주)는 자기 판단 기준이 있다:

> 최근 매수 주체가 개인은 −, 기관·외국인은 + 인 종목을 먼저 보고 연기금이 사는지도 본다. 기관 중 사모펀드 쪽 매수는 잘 안 산다. 매물대를 보고, 1년 안에서 평균가가 어느 정도인지(많이 올랐는지·떨어졌는지·횡보 중인지)를 보고, RSI·MACD·골든크로스를 본다. 비슷한 가격대로 하방을 두 번쯤 찍더라도 MACD 가 살짝씩 우상향하면 가능성 있게 본다. 이게 정답은 아니다.
>
> AI 가 판단하게 하는 게 아니라, 지표와 뉴스를 AI 가 잘 모으고 **판단은 코드가 객관적 지표로** 하게 하자. 어떤 데이터가 오든 우리가 정한 기준과 수치로 판단돼야 한다.

## 2. 목표

- **G1 일관성**: 같은 입력이면 같은 판정(등급·진입/손절/목표·손익비)이 나온다. 판정 근거(조건별 실측값)를 그대로 보여 준다.
- **G2 명문화**: 사용자 체크리스트를 버전 고정 규칙서(`swing-v1`)로 옮긴다. 기준값 변경은 새 버전이다.
- **G3 정직한 성적**: 규칙서를 과거 데이터로 사전 등록 검증하고, 등급별 실제 과거 성적을 표시한다. 우위가 증명되지 않으면 추천이 아니라 체크리스트로 출시한다.
- **G4 prod 즉시 판정**: 매일 아침 전 종목 스크리너 + 종목 즉시 판정이 로컬 워커 없이 돈다.
- **G5 AI 역할 축소**: AI 는 뉴스·공시 수집·요약과 해설만 맡는다. 등급·가격은 바꿀 수 없다.

"적중률 상승"은 약속하지 않는다. 결과이며, 검증이 판정한다.

## 3. 범위 (In scope)

### 3-1. 규칙서 swing-v1 (`lib/swing/rulebook.ts`)

규약
- t = 마지막 확정 거래일. 입력 = t 까지 일봉 300개 + 수급 20일 + (t−20, t] DART 주요사항보고. 진입은 t+1 시가.
- 수급 강도 S_g(N) = 주체 g 의 N일 순매수 합(원) ÷ 20일 평균 거래대금(ADV20). 순매수 원본은 백만원, 거래대금 원본은 **원**(2026-10-31 probe 실측 — 포털 문서의 백만원 표기와 다름).
- 유동성 2단계: 1차 거르기 = 종가×거래량 20일 평균 ≥ 20억(이 단계 통과분만 수급 조회), 확정 = 수급 응답 거래대금 20일 평균 ≥ 30억.

제외(하나라도 해당 → `제외`)
- 데이터 부족(일봉 300 미만, 최근 20일 수급 결측) · 유동성(종가 < 1,000원 또는 ADV20 < 30억) · 거래정지(최근 5봉 중 거래량 0)
- 스팩·리츠(이름 `/스팩/`, `/리츠$/` — 메리츠금융지주 오탐 금지)
- 고변동: ATR14% ≥ 시장별 67퍼센타일(수익률을 보기 전에 분포만으로 고정, 사전 등록 §0 에 기재)
- 과열: 20일 수익률 ≥ 20% 또는 RSI14 ≥ 75
- 자금조달·위험 공시(20거래일 내): 유상증자·전환사채·신주인수권부사채·교환사채·감자·회생·부도·영업정지 결정. 정정(`[`로 시작) 제외

조건
| 키 | 정의 |
|---|---|
| A 수급(1차 관문) | A1 S_개인 ≤ −0.02N, A2 S_외국인 ≥ +0.02N, A3 S_기관 ≥ +0.02N 그리고 사모 순매수 < 기관 순매수의 50%. N = 5(기본), 10(유일한 변형) |
| A+ 연기금 | S_연기금 ≥ +0.004N. 표시·정렬만(점수 제외 — 다중검정 억제) |
| B 매물대·계획 | 손절 근거가 구조적(매물대·쌍바닥)이고 손익비 ≥ 1.5 |
| C 위치·국면 | 단계(과열/바닥권/하락추세/상승추세/횡보/혼조) 중 과열·하락추세가 아님. dev250·1년 거래량가중 평균가 대비 위치는 표시만 |
| D 모멘텀 전환 | (MACD 12/26/9 골든크로스 최근 5봉 ∨ SMA5×20 골든크로스 최근 5봉) ∧ 45 ≤ RSI14 ≤ 70 |
| E 쌍바닥+MACD | 두 번째 바닥 t−10~t−3, 첫 바닥 그 이전 10~60봉, 가격차 ≤ 1 ATR, 사이 반등 ≥ 2 ATR, 이후 더 낮은 저점 없음, MACD i1 < 0 · i2 > i1 · t > i2 |

매매 계획(`computePriceLevels` 250봉·24구간, 비중 ≥ 6% 매물대만)
- 손절 = 지지(쌍바닥이면 저점) − 0.5 ATR. 지지 없음·3 ATR 초과 → 종가 − 2 ATR. 1 ATR 미만 → 1 ATR.
- 목표 = 위쪽 첫 두꺼운 매물대 하단, 상한 2 × 통상 10일 변동폭. 호가 단위 반올림.
- 실행: 손절 < t+1 시가 < 목표 일 때만 매수.

등급: `제외` / `매수 후보` = A∧C∧B∧(D∨E) / `관심` = A∧C∧(B∨D∨E) / `관망`. 정렬 = 연기금 → 손익비 → 종목코드.

뉴스는 v1 에서 채점하지 않는다(과거 시점 백테스트 불가 + LLM 비결정성). 채점하는 공시는 DART 정형 데이터뿐이다.
