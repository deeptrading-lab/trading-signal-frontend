# PRD — 오토파일럿 모멘텀 목표형(+2% 전량 익절)

- 작성일: 2026-08-06
- 브랜치: `feature/intraday-trend-target-2pct`
- 적용 범위: 오토파일럿이 만든 `cli-agent` 모의세션

## 1. 배경·문제

제품의 출발점은 거래량·수급 상위에서 이미 상승 중인 종목을 잡아 하루 포트폴리오 +1%를
관찰하는 자동 단타였다. 현재 엔진은 구조 TP와 AI SELL을 우선해 +0.2% 안팎에서도 전량 청산할 수
있고, 매수 컷 근처의 진입 비중은 20%부터 시작한다. 따라서 종목이 +2% 움직여도 세션 수익은
약 +0.4% gross에 머물 수 있다. 반면 균형 모드 포지션 하드스톱은 −5%여서 고정 +2% 목표와
손익 비대칭도 맞지 않는다.

## 2. 목표

- 거래량/수급 랭킹에서 상승 지속성이 확인된 종목만 오토파일럿 슬롯에 편입한다.
- 엄격한 모멘텀 확인으로 후보가 고갈되지 않도록 1차 상위 12종목까지 분봉을 검토한다.
- 실제 체결 평단 대비 +2%에서 60초 리스크 스윕이 전량 익절한다.
- 진입은 세션 최대 허용 비중(현재 50%)을 사용해 종목 +2%가 세션 약 +1% gross로 연결되게 한다.
- 목표 전 조기청산은 결정론 시그널 SELL 또는 AI 확신 25 이하의 강한 테제 훼손으로 제한한다.
- 실제 평단 −1% 고정 손절, 일일 손실 kill, 세션 하드스톱, 15:00 신규진입 금지,
  15:20 전량청산을 유지한다.

## 3. 전략 다각도 검토

### 3-1. 모멘텀 가설 관점

장중 모멘텀이 고변동·고거래량일에 더 강해진다는 연구는 “상승+거래량 확인” 방향을 지지한다.
다만 대표 연구는 S&P 500 ETF 중심이며 한국 개별주에 +2% 고정 목표가 유효하다는 직접 증거는
아니다. 따라서 거래량/수급 순위만 추격하지 않고 VWAP 위, 상승 스윙/오프닝 돌파/VWAP 재탈환을
함께 요구한다.

- 근거: [Market intraday momentum, Journal of Financial Economics](https://doi.org/10.1016/j.jfineco.2018.05.009)
- 한국 일중 모멘텀 관련 참고: [DTW를 이용한 패턴 기반 일중 price momentum 효과 분석](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002247102)

### 3-2. 체결·비용 관점

현재 모의 비용 모델은 왕복 약 0.28%(수수료·세금·양방향 슬리피지)다. +2% gross 익절은 비용 후
약 +1.72%, −1% gross 손절은 약 −1.28%로 단순 손익분기 승률은 약 42.7%다
(`1.28 / (1.72 + 1.28)`). 비용을 빼면 성과가 과대평가되므로 기존 비용 모델을 유지한다.
모멘텀 수익이 거래비용으로 사라질 수 있다는 연구도 있어 거래량 확장과 거래대금 하한을 편입
조건으로 둔다.

- 근거: [The illusory nature of momentum profits, Journal of Financial Economics](https://doi.org/10.1016/S0304-405X(03)00206-X)

### 3-3. 리스크·시장 미시구조 관점

+2% 목표만 고정하고 기존 −5% 손실 허용을 유지하면 손익분기 승률이 지나치게 높아진다. 그래서
목표와 2:1 gross 손익비를 이루는 −1% 고정 손절을 결합한다. VI 발동 시 2분 단일가매매로 바뀌어
목표가 도달과 실제 체결 사이 괴리가 생길 수 있으므로 기존 경보 조회·슬리피지 기록도 유지한다.

- 근거: [한국거래소 종목별 변동성완화장치](https://regulation.krx.co.kr/contents/RGL/03/03020407/RGL03020407.jsp)

### 3-4. 반대 관점·실패 가능성

- 순위 상위는 이미 오른 결과일 수 있어 +15% 초과 또는 VWAP +3% 초과 이격은 편입하지 않는다.
- −1% 고정 손절은 변동성 큰 종목에서 정상 흔들림에도 잘릴 수 있다. ATR은 편입 점수·관측값으로
  남기고, 충분한 표본 뒤 변동성 조정 손절과 비교한다.
- +2% 목표는 가격 경로를 무시해 +1.8%까지 갔다 되돌아오는 거래를 놓친다. 이번 버전은 사용자
  가설을 깨끗하게 검증하기 위해 트레일링 익절을 섞지 않는다.
- 세 종목이 동시에 같은 시장 충격을 받으면 슬롯 수가 분산을 보장하지 않는다. 세션/일일 손실
  kill과 장 마감 청산은 완화하지 않는다.

## 4. 비범위

- 실계좌 주문, KIS 주문 API, 수익 보장.
- 수동 종목 단타의 기존 적응형 구조 TP/SL 변경.
- +2% 도달 후 분할 익절·트레일링 스톱.
- 당일 바로 전략 우위를 확정하는 주장. 오늘 실행은 모의 관측 1일차다.

## 5. 기능 요구사항·수용 기준

| ID | 요구사항 | 수용 기준 |
|---|---|---|
| AC-1 | 적용 격리 | `autopilotRunId`가 있는 세션만 `momentum-target`, 수동 세션은 `adaptive` |
| AC-2 | 후보 출처·범위 | 1차 상위 12종목을 검토하고 거래량 또는 외국인/기관 수급 랭킹 출처가 없는 후보는 fill 제외 |
| AC-3 | 상승 확인 | VWAP 위 + 상승 스윙/OR 돌파/VWAP 재탈환 중 하나 필수 |
| AC-4 | 거래 확인 | 양수 수급 또는 최근 거래량 z≥0.5 필수 |
| AC-5 | 추격 제한 | 당일 +15% 초과 또는 VWAP +3% 초과 이격 후보 제외 |
| AC-6 | 진입 비중 | BUY 시 세션 `maxPositionPct`를 목표 비중으로 사용(현 기본 50%) |
| AC-7 | 고정 익절 | 보유 평단×1.02를 KRX 호가 단위로 반올림, 도달 시 전량 EXIT |
| AC-8 | 고정 손절 | 보유 평단×0.99를 KRX 호가 단위로 반올림, 이탈 시 전량 EXIT |
| AC-9 | 목표 전 보호 | 시그널 SELL 또는 conviction≤25만 조기 SELL 허용 |
| AC-10 | 60초 검사 | LLM 틱 사이에도 리스크 스윕이 평단 기준 목표/손절을 재계산 |
| AC-11 | 안전핀 | 손실 kill·하드스톱·15:00 신규금지·15:20 청산 불변 |

## 6. 상태·오류 UX

화면 구조는 바꾸지 않는다. 기존 틱의 `gateAdjustments`에 모멘텀 목표형 진입 비중, 고정
익절/손절, 조기청산 보류 사유를 한글로 남긴다. 스크리너 스냅샷의 탈락 후보에는
`모멘텀 목표형(<사유>)`를 기록해 후보가 비는 이유를 사후 확인할 수 있게 한다.

## 7. 측정·판정

- 최소 측정: 거래별 gross/net 수익, 목표/손절/테제훼손/마감 청산 비중, MFE/MAE, 승률,
  profit factor, 일 최대 낙폭, 슬롯 간 상관.
- 동일 종목 반복 틱은 독립 표본으로 세지 않고 왕복 거래 단위로 집계한다.
- 1일 결과로 승격하지 않는다. 최소 20회 왕복과 상승/횡보/하락일 포함 표본에서 기존 적응형과
  비용 후 기대값·낙폭을 비교한다.
- 일 +1%는 관찰 목표 구간이며 보장이나 일일 중단 조건이 아니다.

## 8. 영향 분석

- `intradayCli`: 오토파일럿 전략 모드의 진입 비중·조기청산·목표/손절 후처리.
- `intradayTickDecision`/`sessionStore`: 자식 세션 식별과 60초 평단 기준 리스크 검사.
- `autopilot/screener`: 모멘텀 편입 하드 확인 및 탈락 사유 관측.
- 세션/틱 JSON payload의 기존 필드만 사용해 DB migration 없음.
- 프론트 UI·BFF 계약·실계좌 주문 경로 변경 없음.

## 9. OPEN QUESTION

1. −1% 고정 손절 대신 ATR 손절을 쓸 것인가? **PM 권고: 이번 A/B에서는 −1% 고정.** 목표 가설을
   깨끗하게 측정한 뒤 ATR 반사실로 비교한다.
2. 거래량과 수급 랭킹의 교집합만 허용할 것인가? **PM 권고: 엄격 교집합은 후보 고갈 위험이 있어
   합집합 + 실시간 확인.** 수급 양수 또는 거래량 z≥0.5를 요구한다.
3. +1% 도달 시 하루 전체 런을 중단할 것인가? **PM 권고: 아직 중단하지 않는다.** 포트폴리오 수익은
   체결 비용·비중·동시 손실에 따라 달라지고 표본 수집이 우선이다.
