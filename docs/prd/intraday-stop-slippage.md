# PRD/티켓 — intraday-stop-slippage (단타 손절 틱 슬리피지)

- 작성: 2026-07-09 (라이브 관측 근거)
- 상태: **조사·해결방향 미정** (§7 OPEN QUESTION 결정 필요)
- 선행/맥락: [intraday-decision-overhaul](intraday-decision-overhaul.md) — conviction judge 첫 실전(7/9) 데이터에서 발견

## 1. 배경 / 문제

7/9 첫 실전(conviction judge) 체결 8건 중 **다스코**:
- 진입 5,473원 · 손절선 **5,420원(−1.0%)** 설정 · 실제 청산 **5,077원 = −7.96%**
- 12:00봉이 거래량 동반 장대음봉으로 5,420을 **건너뛰고** 급락 → 다음 5분 틱(12:05)에서야 5,077원에 청산

즉 **손절선(−1%)의 8배(−8%) 손실**이 났다. 원인은 손절 판정·체결이 **틱 주기(이 세션 5분)에 묶여** 있고, 그 사이 가격 급락을 감지·차단하지 못하기 때문이다.

## 2. 근본 원인 (코드)

- **판정 주기 = 틱 주기**: `resolveForcedExit`(`lib/server/paperTrading/virtualExecution.ts:213`)는 틱마다 1회만 호출된다. 손절 조건 `last <= stopPrice` 를 검사하지만, `last` 는 **그 틱의 스냅샷 가격 1개**(5분에 1번 갱신, `PAPER_TRADING_MAX_STALE_PRICE_SECONDS=180` 까지 stale 허용)다. 틱 사이 5분간 가격이 손절선을 뚫고 급락해도 다음 틱까지 감지 못 한다.
- **체결가 = 감지 시점 시장가**: 트리거되면 스톱 레벨(5,420)이 아니라 **감지 틱의 현재가(5,077)** 로 청산한다(EXIT 결정 → 시장가 가상 체결). 갭 하락분이 전부 손실로 실현된다.
- **−5% 포지션 하드스톱 미적용(백스톱 부재)**: `PAPER_TRADING_POSITION_HARD_STOP_PCT=-5` 는 mock 경로 전용이라 **cli-agent(단타) 세션엔 안 걸린다**(intraday-decision-overhaul PR-3a 리뷰 F-1). 그래서 −5%를 넘겨도 다음 틱의 judge/forced-exit 전까진 아무 백스톱이 없다. 다스코가 −8%까지 간 이유.

## 3. 목표 (측정 가능)

- 로그된 손절 손실이 **설정 손절선을 크게 초과하지 않게** 상한을 둔다(예: 실현 손절 손실이 설정 손절폭 + 슬리피지 여유 이내). "−1% 손절이 −8%로 실현" 케이스 제거.
- 5분 주기 세션에서도 **틱 사이 급락**에 대한 손절/백스톱이 작동한다.
- (가상투자 정합) 손절 슬리피지가 리스크 지표(승률·손익비·MDD)를 과대 왜곡하지 않게 해 캘리브레이션 데이터 신뢰도를 높인다.

## 4. 범위 (In scope) — 후보 (택1/조합, §7에서 결정)

- **A. 리스크 전용 경량 체크(권장 후보)**: 스케줄러가 이미 60초 폴링(`tickScheduler`)하므로, **LLM 틱과 별개로** 매 폴링마다 보유 세션의 **신선 가격 대비 손절/익절/하드스톱만** 검사해 트리거 시 즉시 청산. LLM 호출 0(가격 조회만) → 슬리피지를 5분 → ~60초로 축소.
- **B. −5% 포지션 하드스톱을 cli-agent 에도 적용**: mock 전용 백스톱을 단타 경로에도 배선(A의 유무와 별개로 안전핀 하나 추가).
- **C. ATR/변동성 상대 손절폭**: 고변동 소형주는 5분 안에 −1%를 쉽게 뚫으므로, 손절폭을 틱 주기 예상 변동(ATR)에 맞춰 넓혀 "즉시 뚫림"을 줄임(진입 자체를 거를 수도).
- **D. 슬리피지 모델 명시**: 가상 체결이 스톱 레벨이 아닌 시장가로 채워지는 현동작을 "현실적 슬리피지"로 문서화하고, 대신 A/B로 **감지 지연**만 줄인다(체결가 낙관화는 하지 않음).

## 5. 비범위

- 실제 주문/실전 손절(조회·분석 전용 스코프 유지).
- 순수 신호 엔진·백테스트 라벨링 변경(라이브 리스크 계층만).
- 진입 로직(conviction 컷/사이징) 변경 — 별건(overhaul PR-4 캘리브레이션).

## 7. OPEN QUESTION (결정 필요)

- q1. **경량 리스크 체크(A) 도입 여부**. **PM 권고: A + B**(60초 폴링에 가격-only 손절/하드스톱 체크 + cli-agent 하드스톱 백스톱). LLM 비용 0, 슬리피지 5분→60초로 상한, 안전핀 이중화. C(ATR 손절폭)는 PR-4 진입 캘리브레이션과 함께 후속.
- q2. **체결가 정책**. 현재 "감지 시점 시장가" = 현실적(실전 스톱도 슬립). **PM 권고: 유지**(체결가 낙관화 금지, 감지 지연만 A로 축소).
- q3. **우선순위**. 라이브 손실이 실제 발생(다스코 −280k)했으나 가상투자라 금전 피해 0. **PM 권고: 중(中)** — overhaul PR-4(클린 데이터 캘리브레이션) 다음. 단, B(하드스톱 배선)는 저비용이라 먼저 처리 가능.
