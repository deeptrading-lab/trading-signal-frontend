# 한투 후보 조회·갱신 연동

## 2026-10-29 적용

기존 KIS 조회 API를 재사용한다. 후보는 실제 조회이며 매매용 시세·체결은 합성 모델이다.

- 거래량 순위 보통주 최대 14개 + 외국인 순매수 10개 + 기관 순매수 10개, 중복 제거.
- 워커 시작 및 운용 시작 명령에서 조회. 별도 타이머로 60초마다 갱신.
- 외부 조회는 매매 직렬 대기열 밖에서 수행. 결과 적용과 저장만 직렬화하므로 네트워크 응답을 기다리는 동안에도 보유분 점검 가능. 파일 저장 지연까지 분리한 것은 아니다.
- 중복 갱신은 진행 중인 요청 하나로 합침. 시작 조회 중 중지·청산 명령이 들어오면 이전 시작 명령 취소.
- 한 조회라도 실패하거나 후보가 없으면 신규 매수 중지. 120초 만료 검사 유지. 회복 후 자동 시작 없음. 후보에서 제외된 보유분 위험관리 유지.
- 후보의 최신 가격은 목록에 반영되지만 합성 시세 기준가는 종목 최초 편입 시 고정하는 기존 정책 유지.

## 확인 결과

2026-10-29 13:49 KST, 기존 환경변수로 실전 조회 API 호출 성공: status=ready, 중복 제거 후보 26개(거래량 출처 6, 외국인 10, 기관 10). 필터·중복 때문에 요청 상한보다 적을 수 있다. 주문 호출 없이 조회만 수행했다. 이는 한 차례 연결 확인이며 장시간 워커 운용 검증은 아니다.

관련 엔진·후보·갱신 테스트 18개 통과. 타입·수정 모듈 ESLint·HTML 생성 일치 검사 통과.

## 실행에 필요한 설정

기존 `.env`/`.env.local`의 `KIS_APP_KEY`, `KIS_APP_SECRET`, `KIS_ENV=prod` 사용. 로컬에 이미 설정되어 있어 추가 키 입력은 필요하지 않았다. 키·토큰은 문서나 HTML에 기록하지 않는다.

`npm run program:worker`와 `npm run dev` 실행 후 `/intraday`의 프로그램 자동매매 탭에서 후보·조회 상태 확인. 코드 변경을 적용하려면 기존 워커 재시작 필요. 재시작은 신규 매수 중지 상태로 복원한다.

## 실제 시세·실주문 확장 시 추가 작업

|범위|추가로 필요한 것|
|---|---|
|실제 시세로 모의매매|현재가·호가·분봉 수집, 거래량 배율의 비교 기준 확정, 직전 3분 고가 정의, 타임스탬프·거래정지 확인, 호출량 제어·재접속|
|실제 거래 시간|KST 실시간 시계·거래일/휴장·장 상태. 현재 2초=가상 1분 제거|
|후보 운용 품질|거래량/거래대금 정렬 선택, 제외 종목·유동성 기준, 실패 사유·지연시간·갱신 이력 표시, 장시간 장애·복구 검증|
|주문 연동|계좌 유형·번호·상품코드, 모의/실전 환경 분리, 주문·취소·부분체결·거절·잔고 대사·멱등성 구현|
|운영|상시 워커 실행 환경, 전체 API 사용량 관리, 시세 단절 알림, 재시작 복구 검증|

후보 조회만을 위해 계좌번호·주문 권한을 추가할 필요는 없다. 현재 구현은 실계좌 주문 모듈을 포함하지 않는다.
