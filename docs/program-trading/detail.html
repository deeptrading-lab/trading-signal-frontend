↓ 예

↓ 예

02 · 주문 대사 → 매도 우선순위

주문 접수 ≠ 체결한투 주문번호 · 누적 체결량 · 잔고 조회
↳ 매수 미체결 30초 경과 / 후보 제외 → 취소·체결 재확인
↓
부분체결 / 미체결 / 결과 불명?실제 확인된 수량만 포지션·체결 로그 반영
↳ 결과 불명 → 추가 주문 잠금 · 같은 주문 재전송 금지
↓
① 사용자 종료 중 → 미체결 정리·전량 청산취소 응답 후 체결/잔고 재확인
↓ 해당 없으면
② 일일 자산 −2% → 청산·매수 잠금처음 기록한 계좌자산 기준
↓ 해당 없으면
③ 15:20 이후 → 청산·운용 중지KST · 거래 가능한 상태에서만 전송
↓ 해당 없으면
④ 매수가 대비 −1% → 손절손절 가격 보장 없음
↓ 해당 없으면
⑤ 매수가 대비 +2% → 익절해당 없음 → 보유·다음 점검
↓
시장가 매도 → 체결량·잔고 확인잔여 수량만 처리 · 가격 보장 없음 · 중복 매도 금지

03 · 종료 확인 → 정산 → 개선 판단

미체결 취소·부분체결 대사 → 잔여 보유 청산요청 성공만으로 종료 완료 처리하지 않음
↓
미체결 0 · 보유 0 · 최신 잔고 대사 성공?네트워크 실패·결과 불명·입출금/외부거래 차이 → 정산 미확정
↳ 아니오 → 다음 점검 대사 · 불명 주문 자동 재전송 금지
↓ 예
계좌 전 자산 → 후 자산 · 수익률 확정입출금·수동매매가 있으면 계좌 수익률에 영향
↓

↓
목표 1% 이상?세션 시작 목표와 종료 결과 비교
↳ 예 → 규칙 유지 · 보완 제안 없음
↓ 아니오
미달 원인과 검증 가이드 생성자동 코드 변경 없음 · 검토 후 별도 적용
↓
