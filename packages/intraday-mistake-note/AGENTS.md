# AGENTS — AI 단타 오답노트

- 이 패키지의 AI 단타 판단·오답노트 작업을 시작할 때만 `CM.md`를 읽는다.
- `CM.md`는 자동 생성물이다. 직접 편집하지 않고 `sources/<namespace>/*.json`을 수정한 뒤 `merge`한다.
- `SHADOW`는 보수적 참고 문맥이며 하드 게이트나 자동 주문 규칙으로 승격하지 않는다.
- `ACTIVE`도 손실 한도·장 막판 신규진입 금지·강제청산·하드스톱을 완화할 수 없다.
- 실제 체결 순손익, 반사실 틱 라벨, 런 포트폴리오 수익률을 서로 섞지 않는다.
- 다른 개발자는 `sources/peer/`처럼 별도 namespace만 소유한다. 충돌 규칙은 런타임에서 제외한다.
- 원시 세션·틱·비밀값은 이 패키지에 커밋하지 않는다.
