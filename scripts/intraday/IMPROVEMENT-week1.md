### P1b — 손절폭/RRR 재검토

### P2 — 신호/judge 재설계 or 전략 피벗 (P1 결과 후)

## 최종 개선 계획 (2026-07-21 — 반사실 3종 + 부품해부 + 선행정보 리서치 후)

### A. 데이터로 배제된 것 (더 안 팜)
- **P1a 중립regime 게이트**: 흑자 못 만듦(강세≥65도 net 손실). 보류.
- **P1b 손절폭**: 좁혀도(1.0×) 넓혀도(3.0×·무손절) net 악화(−0.86%→−1.44%). 물타기(마틴게일)는 승률 55% **착시** — 여전히 net 음수 + 꼬리위험. 보류. (스크립트 `stop-cf.mts`·`stop-sweep.mts`·`martingale.mts`)
- **부품 해부(`signal-decompose.mts`)**: 4축(추세/모멘텀/거래량/변동성) **전부 forward return 음/무상관**(−0.04~−0.09) → 재가중할 "좋은 축" 없음. structureEvent(돌파 셋업)도 오히려 약간 나쁨. 시간대만 갈림(오전 +0.19%/오후 −0.80%)이나 **시간 차단은 문제 회피지 판단 개선 아님**(오후를 영영 안 할 것 아니므로).

### B. 선행정보 리서치 결론 (★기대치 현실화)
- order flow(호가 불균형·CVD·체결강도)가 "선행" 도메인은 맞음. 근데 학술+실무 근거: **예측 지평 5~30초·거래비용 못 이김**([arxiv 1901.10534](https://arxiv.org/pdf/1901.10534)·[electronictradinghub](https://electronictradinghub.com/leveraging-limit-order-book-imbalances-for-profitable-trading-a-deep-dive-into-recent-research-and-practical-tools/)). 체결강도도 실무자 한계 명시(저거래량 왜곡·심리 지배).
- **우리 5분틱 + CLI 25초 지연과 지평 불일치** → 선행정보는 "**알파**"가 아니라 "**가짜돌파 필터(거부권)**"로만 가치. **강한 엣지는 이 속도/피처로 불가**가 정직한 결론.

### C. 주기 단축 = 기각
- edge는 초 단위(LLM 지연으로 도달 불가) · 짧은 봉=노이즈(과거 2분=1분봉 노이즈 확인) · CLI 과부하. **5분 유지**(오히려 스윙 쪽 검토가 방향).

### D. 실제 시도할 개선 (기대치 = 손실감소/본전, 강한 엣지 아님)
1. **I1 일봉 컨텍스트 강화** ✅ **구현 완료(de95c56)** — `lib/signal/dailyContext.ts`: MACD 골든/데드크로스·RSI(과매수/과매도)·이평 배열(정/역)·전고/전저 대비 위치·최근5일 추세를 요약해 judge 프롬프트 `[일봉 흐름]` 블록으로 주입(기존 레짐 한 줄 → 상세). buildContext 재사용·당일 캐시. 실데이터 검증 OK(삼성=조정·모나미 RSI92 과매수 등). **⚠️ 라이브 반영=dev 재시작 필요** → 다음 5일 `daily-log` 로 선택·스탠스 개선(≥65WR·net) 관찰.
2. **I2 셋업 우선순위 + 충돌 규칙** — "여러 피처 평균 종합" → "**소수 A+ 셋업이 정렬됐을 때만 진입, 엇갈리면 관망**". 어떤 지표를 트리거/어떤 걸 거부권으로 명시. ★가장 근본적(평균이 엣지를 희석하던 문제 직격).
3. **I3 선행정보 = 필터** — 체결강도·호가 불균형을 **확인·거부권**으로(돌파인데 체결강도 매도우위=흡수 → 진입 보류). 나쁜 트레이드 감소용, 알파 아님.

### E. 검증 방식
- 백테스트 불가(LLM 과거 재실행 불가 + 과거 호가·분봉 데이터 없음) → 각 개선을 이 브랜치에 구현 → **5일 라이브** → `daily-log.tsv`(convSpear·≥65WR·net) 개선 확인. (forward A/B 는 개선 on/off 라이브 병렬이 이상적이나 세션 수 제약.)

### F. ★ 정지 조건 (무한 반복 방지)
- I1~I3 다 적용 후에도 여러 사이클 **forward skill 0/음수 · 손익분기(33%) 미달**이면 → **자동 진입 접고 decision-support / 스윙 호라이즌으로 전환**. (원 스캘핑 NO-GO + 이번 주 결론 존중. sunk cost 방지.)

### G. 순서
**I1(싸고 명확) → I2(A+ 셋업 설계) → I3(호가/체결강도 배선)** — 각각 구현 → 5일 → 측정. 한 번에 하나씩(무엇이 효과냈는지 격리).
